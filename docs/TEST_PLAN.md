# 🧪 测试方案

## 前置条件

```bash
# 终端 1 — 后端
mvnw spring-boot:run

# 终端 2 — 前端
npm --prefix h-ai-agent-frontend run dev
```

浏览器打开 `http://localhost:5173`，先注册账号并登录。

---

## 一、基础功能

| # | 测试项 | 操作 | 预期 |
|---|--------|------|------|
| 1 | 健康检查 | `curl http://localhost:8123/api/health` | `ok` |
| 2 | 注册 | 导航栏 → 注册 | 自动登录，跳转首页 |
| 3 | 登录 | 导航栏 → 登录 | 显示用户名 |
| 4 | 账户管理 | 导航栏 → 账户 | 可修改邮箱和密码 |
| 5 | 管理员 | 数据库设置 role=ADMIN → 刷新 → 管理 | 用户列表/改角色/重置密码/删除 |
| 6 | 会话管理 | 侧边栏 ☰ → 新会话/切换/重命名/删除 | 各模块会话隔离 |
| 7 | 历史恢复 | 关闭页面 → 重新打开 → 切换会话 | 历史消息恢复 |

## 二、AI 智能客服 · 店小二（`/shop-mate`）

| # | 测试项 | 输入 |
|---|--------|------|
| 1 | 售前咨询 | `顾客说我家比隔壁贵20块，怎么回` |
| 2 | 售后纠纷 | `买家说鞋子开胶了要投诉，帮我写回复` |
| 3 | 差评投诉 | `有个差评说发货太慢，怎么解释` |
| 4 | RAG 知识库 | `亲，第一次来怎么快速找到心仪商品` |
| 5 | 多轮对话 | 连续提问，看上下文是否连贯 |
| 6 | 会话持久化 | 发送后刷新页面 → 切换会话 → 历史恢复 |

## 三、HManus 超级智能体（`/manus`）

| # | 测试项 | 输入 |
|---|--------|------|
| 1 | 网页搜索 | `搜索2026年最受欢迎的5款篮球鞋` |
| 2 | PDF 生成 | `搜索上海跑步公园，生成PDF保存` |

## 四、多 Agent 编排器（`/orchestrator`）

| # | 测试项 | 输入 | 预期路由 |
|---|--------|------|----------|
| 1 | 电商路由 | `帮我写一个差评回复` | → ShopMate |
| 2 | 通用路由 | `搜索北京旅游攻略，生成PDF` | → HManus |
| 3 | 会话隔离 | 新建会话2 → 发不同请求 → 切回会话1 | 互不干扰 |
| 4 | 历史恢复 | 关闭后重新打开 → 切回旧会话 | 消息完整 |

## 五、管理员

| # | 操作 | 预期 |
|---|------|------|
| 1 | ADMIN 登录后导航栏出现「管理」 | 用户表格正常显示 |
| 2 | 下拉框改角色（USER/ADMIN） | 即时生效 |
| 3 | 点击「重置密码」 | 密码重置为 init123456 |
| 4 | 点击「编辑」→ 修改用户名/邮箱 → 保存 | 信息更新 |
| 5 | 点击「删除」→ 确认 | 用户消失 |

## 六、边界情况

| # | 场景 | 预期 |
|---|------|------|
| 1 | 未登录访问 AI 页面 | 可匿名对话（无历史保存） |
| 2 | 未登录访问 `/profile` | 跳转登录页 |
| 3 | 后端未启动时访问前端 | 页面不崩溃，提示错误 |
| 4 | 输入空消息 | 发送按钮禁用 |
| 5 | 错误密码登录 | 提示"邮箱或密码错误" |
